## 💡 CUSTOMIZATION QUICK START

### Change Visualizer Settings
Edit `window.VIB34DConfig` in `index.html` (line 573):

```javascript
window.VIB34DConfig = {
  visualizerCount: 1,           // Canvas per section
  defaultGeometry: 'hypercube', // Master geometry
  defaultPreset: 'editorial',   // Visual style
  enableCrystalUI: true,        // Global overlay
  targetFPS: 60,                // Performance target
  debugMode: false              // Production mode
};
```

### Modify Section Geometries
Edit HTML `data-geometry` attributes:

```html
<section data-section="home">          <!-- Hypercube -->
<section data-section="articles" data-geometry="tetrahedron">
<section data-section="videos" data-geometry="sphere">
<section data-section="podcasts" data-geometry="torus">
<section data-section="ema">           <!-- Wave -->
```

### Adjust Parameter Relationships
Edit `js/vib34d-home-master.js`:

```javascript
articles: { geometry: 'tetrahedron', modifier: 0.8 },  // Calmer
videos: { geometry: 'sphere', modifier: 1.2 },         // More intense
```
