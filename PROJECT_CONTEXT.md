## 🎨 VIB34D STYLE SYSTEM CONCEPT

### MULTI-INSTANCE VISUALIZER FRAMEWORK:
- **Each section:** Multiple full visualizer instances (same geometry, varied parameters)
- **Flexible assignment:** Header backgrounds, content boxes, total backgrounds, etc.
- **Mathematical relationships:** All instances derive from home-master parameters
- **Reactive form:** UI maintains relational structure even when "scrambled"

### GEOMETRY-BASED SECTION THEMES:
- **HOME:** Hypercube (master control)
- **ARTICLES:** Tetrahedron 
- **VIDEOS:** Sphere
- **PODCASTS:** Torus  
- **EMA:** Wave
- **CRYSTAL:** Universal UI framework (future addition)

### PARAMETER DERIVATION SYSTEM:
```
Home.gridDensity = 12
├── Articles = Home × 0.8 = 9.6
├── Videos = Home × 1.2 = 14.4
└── Instance variations within section:
    ├── Instance1 = base
    ├── Instance2 = base × 1.3
    └── Instance3 = base × 0.7
```

### INTERACTION REACTIVITY:
- **Scroll velocity** → Grid density, dimension shifts
- **Click events** → Glitch spikes, morphology changes
- **Hover/touch** → Localized parameter modifications
- **Inactivity timing** → Return to calm base states
- **Hold interactions** → Progressive 4D transformation
